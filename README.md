## Управление таблицами

### Доступные команды

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` - Создать новую таблицу с указанными столбцами
- `list_tables` - Показать список всех существующих таблиц
- `drop_table <имя_таблицы>` - Удалить таблицу
- `help` - Показать справочную информацию
- `exit` - Выйти из программы

Поддерживаемые типы данных для столбцов: `int`, `str`, `bool`

Столбец `ID:int` добавляется автоматически в начало каждой создаваемой
таблицы и не указывается пользователем вручную.

### Пример использования

\`\`\`
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.

>>>Введите команду: help
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу
<command> exit - выход из программы
<command> help - справочная информация

>>>Введите команду: exit
\`\`\`


## CRUD-операции

После того как таблица создана, с данными внутри неё можно работать с
помощью команд insert, select, update, delete и info.

### Доступные команды

| Команда | Описание |
|---|---|
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | Добавить новую запись в таблицу |
| `select from <имя_таблицы>` | Показать все записи таблицы |
| `select from <имя_таблицы> where <столбец> = <значение>` | Показать записи, удовлетворяющие условию |
| `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` | Обновить записи, удовлетворяющие условию |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить записи, удовлетворяющие условию |
| `info <имя_таблицы>` | Показать структуру таблицы и количество записей |
| `help` | Показать справочную информацию |
| `exit` | Выйти из программы |

### Важные замечания

- Столбец `ID` генерируется автоматически и не указывается в команде
  `insert` — значения передаются только для остальных столбцов, в том
  порядке, в котором они были объявлены при создании таблицы.
- Все поля являются обязательными.
- Строковые значения необходимо указывать в двойных кавычках
  (например, `"Sergei"`), иначе они будут восприняты как число или
  логическое значение.
- Логические значения записываются как `true` / `false` (без кавычек).
- Данные каждой таблицы хранятся в отдельном JSON-файле в директории
  `data/`, например `data/users.json`.

### Пример использования

\`\`\`
***Операции с данными***

Функции:
<command> insert into <имя_таблицы> values (<значение1>, <значение2>, ...) - создать запись.
<command> select from <имя_таблицы> where <столбец> = <значение> - прочитать записи по условию.
<command> select from <имя_таблицы> - прочитать все записи.
<command> update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия> - обновить запись.
<command> delete from <имя_таблицы> where <столбец> = <значение> - удалить запись.
<command> info <имя_таблицы> - вывести информацию о таблице.
<command> exit - выход из программы
<command> help - справочная информация

>>> Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>> Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |

| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>> Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>> Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>> Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0

## Обработка ошибок и дополнительные возможности

На финальном этапе разработки в проект добавлены декораторы, которые
расширяют функциональность основных операций без изменения их кода.

### Централизованная обработка ошибок

Все функции модуля `core.py`, работающие с таблицами и данными, обёрнуты
декоратором `handle_db_errors`. Он перехватывает исключения
(`FileNotFoundError`, `KeyError`, `ValueError` и прочие непредвиденные
ошибки) и выводит понятное сообщение пользователю вместо аварийного
завершения программы.

### Подтверждение опасных действий

Операции `drop_table` (удаление таблицы) и `delete` (удаление записи)
обёрнуты декоратором `confirm_action`, который запрашивает подтверждение
перед выполнением:

\`\`\`
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
\`\`\`

Если ввести что-либо, кроме `y`, операция будет отменена:

\`\`\`
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.
\`\`\`

### Замер времени выполнения

Операции `insert` и `select`, работающие с файлами данных, обёрнуты
декоратором `log_time`, который выводит время их выполнения:

\`\`\`
>>>Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+
Функция select выполнилась за 0.001 секунд.
\`\`\`

### Кэширование результатов select

Результаты команды `select` кэшируются с помощью замыкания
`create_cacher`. Повторный запрос с теми же данными и тем же условием
возвращается из кэша без повторной фильтрации, что ускоряет выполнение
повторяющихся запросов. Кэш автоматически перестаёт быть актуальным,
как только данные таблицы изменяются (например, после `insert`,
`update` или `delete`).
